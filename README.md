2. Click the Load button. The software transfers the model from your hard drive to your graphics card memory. This step requires a few seconds.

4. Press the Enter key.
5. The software processes your request. It displays the text response in the main window.

## 📈 Performance Tips

You want the best speed when you use language models. Follow these suggestions to keep the software running smooth.

- Close web browsers and other heavy programs while you use ktransformers. These programs take up memory that your models need.
- Keep your computer cool. If your computer gets too hot, the hardware limits its own speed. Ensure your desktop or laptop has proper airflow.
- Use the settings menu to adjust the performance balance. You can allocate more memory to the model if your system has plenty of RAM.
- Check for updates regularly. We improve the software to use hardware more efficiently with every version. The software notifies you when a new version exists.

## 🛠️ Troubleshooting

If you see errors, try these solutions:

- The program does not start: Verify your graphics drivers are current. Older drivers often cause crashes.
- The model fails to load: You likely ran out of video memory. Try a smaller model or close other programs using your graphics card.
- The text generation feels slow: Check that you selected the correct graphics card in the settings menu. Sometimes computers with two graphics cards choose the slower one.
- The screen freezes: Give the application time to think. Large calculations occupy all your resources for a short moment. It should respond again after a few seconds.

If you encounter issues beyond these, check the official website for community discussions and frequently asked questions. Keep your workspace organized and ensure you have enough disk space for the models you want to run.
